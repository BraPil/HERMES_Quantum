# Library

This directory contains shared libraries, utilities, and common functionality used across the HERMES_Quantum system.

## Purpose

The library package provides:
- Base classes for agents and components
- Common data structures
- Shared constants and enumerations
- Utility functions used across multiple modules
- Configuration helpers

## Usage

```python
from library import BaseAgent, StockData, constants
```

## Contents

- `base_agent.py` - Base class for all agents
- `data_structures.py` - Common data structures
- `constants.py` - System-wide constants
- `utils.py` - Shared utility functions
- `exceptions.py` - Custom exception classes
