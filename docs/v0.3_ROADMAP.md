## Objective

Integrate real sentiment analysis agents with the dashboard to replace placeholder signals with actual AI-driven insights.

## Primary Goals

2. **Agent 23 (Social)**: Real social sentiment via StockTwits + Reddit
3. **Persistence Layer**: SQLite database for signal tracking
4. **Event Bus**: Agent-to-dashboard communication
